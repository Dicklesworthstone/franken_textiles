Pattern Workbench

Draft a sewing pattern from measurements, check every seam and fit point, and download print-at-home PDFs and cutter files. It runs FrankenTextiles in this page (Rust compiled to WebAssembly, about 2 MB), so nothing you type leaves your browser. The fold-up check on a fitted body and tracing AI pattern sheets need the command line (ftx, or the skill's fab).

1. Garment

Without a fit spec the checks use role-based defaults.

2. Body

Tape measurements in cm (degrees where marked). ● = needed for this garment; the rest improve it. Empty boxes fall back to the size chart for this height, shown greyed, and the check below says which ones still need measuring.

3. Style (optional)

The drafting program's style parameters (ease, lengths, proportions). Edit the values; the result is checked against the same fit contract.

Fold it up on a fitted body

      
Sews and drapes this pattern on an Anny body fitted to the measurements above, as
        ftx drape does (cloth self-contact at Blender's 2 mm). It needs the converted body model,
        anny-0.6.1-default.ftxbody (about 150 MB, made by FrankenTextiles'
        tools/body-model/convert_anny.py); the file stays in this page. A bolero takes about half a
        minute, trousers a minute or two.
