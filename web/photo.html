Photo measurements and body fitting

Measure lengths or angles using a flat reference sheet in the photo: blank US Letter/A4 or a printed ChArUco calibration board, with optional lens calibration created here or retained from an earlier session. Photos and clicks stay in this browser; nothing is uploaded or saved in browser storage. Return to the Pattern Workbench.

Calibrate a camera locally — optional

Identify the camera from several views of a measured, rigid, flat reference. Supply your declared lens model, unchanged capture settings, actual frame identities and FIT/CHECK assignments before fitting. Use different out-of-plane tilts. The shared calibration engine keeps every acquired corner and reports failed gates.

The manifest uses ftx-camera-calibration-images/1. Each views[].image must exactly match a selected filename, or a path relative to the chosen directory. Select either files or a directory. All selected PNG/JPEG photos must be declared; other directory files are ignored. Up to 32 images are read and detected one at a time. No FIT/CHECK split, timestamp, image model or noise value is inferred.

Coordinate input uses ftx-camera-calibration-input/1. Separate noise uses ftx-calibration-corner-noise/1; keep its uncertainty and independence evidence explicit. Do not combine separate noise with an inline noise declaration. JSON limits: 16 MiB for input/noise, 256 KiB for the sheet; each image has the ordinary 64 MiB/16-million-pixel limit. See the camera calibration input guide for the exact schemas and capture requirements.

5. Reconstruct landmarks from calibrated views

  
Load prepared observations of stationary landmarks from at least two calibrated views.
    Cameras must share a metric, z-up world and the original oriented-pixel coordinates.
    Declare a reviewed still window or synchronized capture; unrelated frames of a moving person do not qualify.

  
  
  

    
    
    
Click uncertainty is conditional on fixed cameras, scale and capture;
      it excludes calibration error, motion and systematic error. Missing uncertainty remains unavailable.

  

  

    
    
Joint refinement requires at least four well-spread fixed metric controls in every camera.
      Use the same stationary reference and world frame throughout. Initial camera and landmark guesses are not observations.

    
Each observation supplies its own pixel sigma. Switching to joint refinement clears the separate click-noise selection.
      Intrinsics stay fixed; no camera covariance or global optimum is established. Failed or budget-stopped solves publish no optimized geometry.

  

  

    
Supply 4–64 calibrated frames from one stream with at least three FIT landmarks tracked in every frame.
      Include independent held-out landmarks. Cameras must share a stationary metric reference.

    
The input declares its own motion threshold. Early/late triangulation and complete-interval
      reprojection checks can reject motion or weak geometry. A passing candidate still requires human review:
      it does not create reviewed capture evidence, verify untracked anatomy or establish measurement accuracy.

  

  
Each input file is limited to 256 KiB. Review the complete native report before using any geometry.

6. Fit one body shape across changing poses

  
Fit the same Anny shape to calibrated observations from several photographs, with a separate
    pose for each frame and optional tape constraints. Begin with local still photographs below, or load
    an existing ftx-anny-body-fit-input/1 request. This runs the same bounded fitter as
    ftx measure fit-body, locally in a cancellable worker.

  
  

    Start a body capture from local still photographs
    
Prepare the calibrated cameras and an empty observation draft, then use the target, observation
      and starting-value editors below. Choose 2–8 distinct photographs of the same wearer with the same
      stationary upright ChArUco sheet visible. The checked calibration must describe the same lens,
      oriented image size and recorded rotation. All image decoding and fitting stay in this browser.

    
    
    
    

      
      
      
    

    

      
      
    

    
    
Declare at least four CHECK corner IDs before acquisition and leave at least four other
      corners for camera fitting. CHECK corners are excluded from fitting and must pass the same
      reprojection check in every photograph. The sheet lies at world y = 0, with printed
      right along +x and printed up along +z. Enter the same measured sheet origin for the whole capture.

    
    

    

      

      

        
        
      

      
Age and the Anny gender coefficient (0 male, 1 female) are explicit fixed model inputs.
        They are not inferred from photographs.

          displayed model defaults; these are assumptions, not measurements.

Root placement and articulated motion
        
All six root components begin explicitly fixed at zero. Choose the components to fit and
          enter bounds in metres or radians. Root rotations are rotation-vector components, with a
          combined fixed rotation length of at most π. Fit at least one and at most eighteen root or
          joint controls; each photograph receives its own pose values in the starting-value editor.

          Unselected joints remain at rest. The page does not infer or normalize an axis.

Camera acquisition diagnostics

    
Use already-oriented opaque PNG or JPEG bytes with absent or identity EXIF orientation;
      the rotation setting records a prior pixel rotation and does not rotate images. Each image is
      limited to 64 MiB and 16 million pixels; the batch to 128 million pixels. Calibration is limited
      to 16 MiB and the sheet sidecar to 256 KiB. Distinct source streams use zero as their own clock
      origin, so these stills establish no timing or synchrony. This creates no anatomical targets,
      fitted body, measurement readiness, camera accuracy qualification or garment-fit claim.

  

  
  
The request declares the exact model hash, calibrated cameras, anatomical correspondences,
    FIT/CHECK roles, parameter bounds and every initialization. Reviewed inline silhouette slices are
    supported. A path-based capture input or mask manifest must first be prepared with the native tools;
    this page does not read local paths or infer landmarks from a video. Input limit: 16 MiB; model limit: 512 MiB.
